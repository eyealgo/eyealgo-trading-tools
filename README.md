# Eye Algo Trading Tools

Open-source TradingView Pine Script strategies and MT5 Expert Advisors by Eye Algo (https://eyealgo.com).

Every strategy has editable inputs for stop loss, take profit (risk:reward), partial close, break-even and ATR trailing. Signals are calculated on closed bars.

## Pine Script strategies (TradingView)

HalfTrend + EMA Trend Filter, Time-Based Entry and Exit, MACD Crossover, Bollinger Bands Bounce / Breakout, Donchian Channel Breakout, Supertrend Multi-Timeframe Pyramiding, Session Opening Range Breakout, Supertrend with HTF Filter and Info Panel, Candlestick Pattern Strategy and Scanner.

How to use: open the Pine Editor on TradingView, paste a script, press Add to chart.

## MT5 Expert Advisors (MQL5)

The same ideas as MT5 Expert Advisors are in the mt5 folder. Copy the files to MQL5/Experts, open in MetaEditor, press Compile (F7) and test in the Strategy Tester before any live use.
